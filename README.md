# huizhang95.github.io

A minimal, modern static site (no Jekyll needed). Deploy on GitHub Pages:

1) Create a **public** repository named `huizhang95.github.io`.
2) Upload all files from this folder to the repo root and commit.
3) In **Settings → Pages**, ensure the site is served from the `main` branch (root).
4) Visit https://huizhang95.github.io

To customize:
- Edit `index.html`, `projects.html`, `publications.html`, `cv.html`
- Replace the PDF at `assets/cv/Hui_Zhang_resume_latest_en.pdf`
- Update links to your GitHub, demos, and publications
